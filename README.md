# Fluxa

A modern financial management platform focused on your real available balance.

## Features

- Dashboard with financial insights
- Expense and income tracking
- Accounts payable
- Dynamic insight cards
- Interactive charts
- JWT Authentication

## Stack

### Frontend
- Next.js
- React
- TypeScript
- TailwindCSS

### Backend
- Spring Boot
- Spring Security
- Spring Data JPA
- PostgreSQL
